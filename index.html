项目介绍

BOSS 直聘 Windows 桌面端 自动化Skill 合集

查看 GitHub 项目 ↗

面向 BOSS 直聘 Windows 桌面端，提供岗位发布、候选人初评分、批量及定向沟通、简历索要与收取能力。 4 个可组合 Skill 可独立安装，也可按招聘流程组合调用。

  1. 01

    岗位发布

    支持 4 类岗位，填写并核验职位、JD、薪资、学历等字段后发布。

  2. 02

    候选人初评分

    读取岗位 JD 与消息页候选人资料，输出匹配分数、依据与信息缺口。

  3. 03

    候选人沟通

    支持批量打招呼、文档回复、批量消息与指定联系人发送。

  4. 04

    简历索要与收取

    支持平台或消息索要简历，下载 PDF / DOCX 后完成校验与解析。

个人微信本地聊天记录读取器

查看 GitHub 项目 ↗

读取和分析本地微信聊天记录的 Agent Skill，支持查询会话、读取消息和生成聊天总结。

  1. 01

    查询聊天会话

    列出本地微信中的联系人和群聊，帮助快速找到想查看的聊天对象。

  2. 02

    读取聊天消息

    读取指定联系人或群聊的消息，可查看消息时间和正文内容。

  3. 03

    按时间筛选

    只读取指定日期或时间范围内的聊天记录，快速定位需要的信息。

  4. 04

    生成聊天总结

    统计消息数量、归纳主要话题，并整理聊天中出现的链接和外部资源。
